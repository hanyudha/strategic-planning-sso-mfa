# Scope & Boundary — LOCKED

## Project Title
**Perencanaan Strategis Pengembangan Single Sign-On (SSO) Terintegrasi Multi-Factor Authentication (MFA) untuk Meningkatkan Keamanan Layanan Digital Perguruan Tinggi**

## In Scope

### Technology
- Existing SSO
- MFA
- Identity and access management directly related to SSO
- Authentication
- Authorization only where directly relevant to SSO/MFA
- SSO-integrated applications
- Authentication monitoring and logging

### Organization
- SSO ownership
- IT management
- User management
- Relevant governance
- Policies and SOPs
- User lifecycle directly related to authentication

### Strategy
- Business environment
- IS/IT environment
- Strategic issues
- Gap analysis
- IS Strategy
- IT Strategy
- IS/IT Management Strategy
- Target architecture
- Portfolio
- Roadmap
- KPI

## Out of Scope

The following are not primary study objects:
- Full Zero Trust Architecture
- Full SOC/SIEM implementation
- Endpoint security program
- General network security program
- General disaster recovery program
- Enterprise-wide architecture unrelated to identity/access
- Building a new SSO from zero
- Detailed application coding
- Detailed MFA product configuration
- Vendor procurement
- Penetration testing

## Scope Discipline

When a new topic appears, classify it:

1. **Core scope** — directly required to answer the SSO + MFA strategic planning problem.
2. **Supporting context** — useful evidence or context but not a separate research topic.
3. **Future direction** — potentially relevant after the main target is achieved.
4. **Out of scope** — do not develop further.

## Future Direction
Possible future directions include:
- Zero Trust
- Passwordless authentication
- Adaptive/risk-based authentication
- FIDO2/passkey

These may be mentioned only after the core strategic plan has been established.

## Non-Negotiable Rule
Do not let technology enthusiasm redefine the research problem.
The business/organizational requirement must drive IS/IT recommendations.
