# Methodology — Ward & Peppard

## Primary Framework

Ward & Peppard is the primary strategic planning framework for this project.

The supplied reference material presents four environmental perspectives:

1. Internal Business Environment
2. External Business Environment
3. Internal IS/IT Environment
4. External IS/IT Environment

The framework is used to connect organizational/business needs with:
- Business Strategy
- IS Strategy
- IT Strategy
- IS/IT Management Strategy
- Application Portfolio

## Supporting Analysis Methods

Potential methods include:
- SWOT
- PESTEL
- Value Chain
- Stakeholder Analysis
- McFarlan Strategic Grid
- Gap Analysis

Not all methods are mandatory. Select methods based on their relevance and the evidence available.

## Method Selection Principle

Do not include an analysis tool merely because it appears in an example paper.

For each method, document:
- Why it is needed
- What evidence it uses
- What output it produces
- How that output affects the strategy
