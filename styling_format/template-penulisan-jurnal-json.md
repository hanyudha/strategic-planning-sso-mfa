### 2.2 Metode Ward and Peppard

#### 3.1.1 Analisis SWOT
Hasil analisis SWOT dipetakan dalam matriks kekuatan (*Strengths*), kelemahan (*Weaknesses*), peluang (*Opportunities*), dan ancaman (*Threats*).

**Gambar 2. Hasil Analisis SWOT**  
*(Atau sajikan dalam bentuk tabel jika diperlukan)*

- **Strategi SO**: Memanfaatkan kekuatan untuk menangkap peluang.
- **Strategi ST**: Memanfaatkan kekuatan untuk mengantisipasi ancaman.
- **Strategi WO**: Meminimalkan kelemahan dengan memanfaatkan peluang.
- **Strategi WT**: Meminimalkan kelemahan dan menghindari ancaman.

## RANGKUMAN ATURAN STYLING & FORMATTING (STYLE GUIDE)

| Elemen Naskah | Aturan Format Markdown / Styling | Contoh pada Sumber |
| :--- | :--- | :--- |
| **Header Jurnal** | Di bagian paling atas memuat Volume, Nomor, Bulan, Tahun, e-ISSN, DOI, dan Nama Jurnal | `Volume 3, Nomor 2, Desember 2021 e-ISSN 2685-998X DOI 10.30865/json.v3i2.3634` [1] |
| **Judul Artikel** | BOLD, Ukuran terbesar, Title Case / Sentence Case, posisi tengah (*centered*) | `**Perencanaan Strategis Pada Sistem Informasi dengan Menggunakan Metode Ward and Peppard**` [1] |
| **Identitas Penulis** | Cetak tebal (*bold*) untuk nama penulis, penanda nomor/bintang untuk korespondensi, diikuti program studi, fakultas, institusi, email, serta riwayat tanggal (*Submitted, Accepted, Published*) | `**Brian Farrel Hermanto*, Andeka Rocky Tanaamah**` [1] |
| **Abstrak (Indo)** | Diawali dengan kata `**Abstrak–**` tebal, diketik tegak (*normal*) dalam 1 paragraf | `**Abstrak–CV. Bumi Printing adalah...**` [1] |
| **Kata Kunci** | Diawali dengan `**Kata Kunci:**`, dipisahkan dengan tanda titik koma (`;`) | `**Kata Kunci: Ward and Peppard; Perencanaan Strategi SI/TI; ...**` [3] |
| **Abstract (Eng)** | Diawali dengan kata `**Abstract–**` tebal, diketik miring (*italic*) dalam 1 paragraf | `**Abstract–CV. Bumi Printing is a company...**` [4] |
| **Keywords (Eng)** | Diawali dengan `***Keywords:***` miring-tebal | `***Keywords: Ward and Peppard; IS/IT Strategic Planning; ...***` [6] |
| **Judul Seksi Utama** | Menggunakan penomoran angka arab diawali huruf kapital tebal (e.g., `## 1. PENDAHULUAN`, `## 2. METODOLOGI PENELITIAN`) | `**1. PENDAHULUAN**`, `**2. METODOLOGI PENELITIAN**` [6, 16] |
| **Sub-Seksi** | Penomoran bertingkat tebal/miring (e.g., `### 2.1`, `#### 3.1.1`) | `**2.1 Perencanaan Strategis**`, `***2.3 Metode Ward and Peppard***` [16, 19] |
| **Sitasi Pustaka** | Gaya IEEE menggunakan nomor dalam kurung siku `[1]`, `[2]`, `[3]` sesuai urutan kemunculan di teks | `...di dalam perusahaan[1].`, `...dengan dunia usaha [2].` [6, 7] |
| **Judul Gambar** | Format `**Gambar X. Nama Gambar**`, ditempatkan di bawah gambar | `**Gambar 1. Perencanaan Strategis Informasi Ward & Peppard**` [22] |
| **Judul Tabel** | Format `**Tabel X. Nama Tabel**` | `**Tabel 1.**` / `***Tabel strategic Ward and Peppard McFarlan***` [31, 43] |
| **Daftar Pustaka** | Ditulis di bawah header `## REFERENCES`, diformat berbasis nomor `[1]`, `[2]` mengikuti standar IEEE | `[1] N. Sudzhana, “Perencanaan Strategis...”` [52] |
