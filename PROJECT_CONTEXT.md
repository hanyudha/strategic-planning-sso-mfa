# Project Context — SSO + MFA Strategic Planning

## 1. Academic Context
Course: **Perencanaan Stratejik**

The intended output follows the general structure of a Strategic Information Systems / IS-IT Strategic Planning study, using Ward & Peppard as the primary framework.

## 2. Case Context
The organization is a higher-education institution.

The SSO is:
- already operational;
- already used as an authentication mechanism for digital services;
- not yet integrated with Multi-Factor Authentication (MFA).

The exact organizational facts, architecture, identity provider, user population, integrated applications, policies, and infrastructure must be collected in M1 and must not be invented.

## 3. Strategic Problem Statement — Working Version
The existing SSO centralizes authentication for digital services, but authentication currently does not use MFA. The strategic planning problem is to determine how the existing SSO should be strengthened through MFA so that authentication security, governance, and digital-service access can be improved in a structured and organization-aligned manner.

This wording is a working statement and may be refined after evidence is collected in M1–M7.

## 4. Strategic Objective — Working Version
To formulate an IS/IT strategy for strengthening the existing SSO through MFA integration in order to improve the security and governance of access to university digital services.

This is not yet the final measurable objective.

## 5. Current State vs Target State

### Current State
Existing SSO without MFA.

### Target State
Existing SSO strengthened with an appropriate MFA capability, supported by suitable governance, policy, management, architecture, and implementation roadmap.

Do not assume the MFA technology or product before the analysis.

## 6. Expected Analytical Chain
1. Organizational context
2. Current SSO state
3. Internal business environment
4. External business environment
5. Internal IS/IT environment
6. External IS/IT environment
7. SWOT / other justified strategic analysis
8. Strategic issues
9. Gap analysis
10. IS Strategy
11. IT Strategy
12. IS/IT Management Strategy
13. Target architecture
14. Portfolio
15. Strategic initiatives
16. Implementation roadmap
17. KPI / strategic measurement

## 7. Important Constraint
Every major recommendation should be traceable:

**Evidence -> Finding -> Strategic Issue -> Objective -> Initiative -> Technology/Capability -> Roadmap -> KPI**

Avoid recommendations that appear without analytical justification.
